# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリはネットワーク上に配置して複数人で共有できる
- ローカルリポジトリは自分のPCでの配置するため


## プッシュとマージの違いは何でしょうか？
- プッシュはローカルリポジトリの変更履歴をリモートリポジトリへ送信すること
- マージとは枝分かれして作業した内容を結合すること


## コミットとプッシュの違い
- コミットは作業内容をローカルリポジトリに記憶する
- プッシュはリモートリポジトリへ変更履歴を共有できる


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- 編集内容を正確に表すようなメッセージ


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- ローカルでマージするフローは自分のPC上で作業して統合まですること
- プルリクエストでマージするフローはリモートリポジトリ上で、開発者にレビュー依頼して、承認を得てから統合すること


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- 自分以外の人とが書いたソースコードの内容を把握する必要がるため、書いた人と相談して確認してから統合する
