# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリはネットワーク上に配置して複数人で共有するためのリポジトリ
- ローカルリポジトリは自分のPC上に配置するためのリポジトリ


## プッシュとマージの違いは何でしょうか？
- プッシュはローカルリポジトリの変更履歴をリモートリポジトリへ送信すること
- マージとは枝分かれして作業した内容をmasterブランチに取り込むこと


## コミットとプッシュの違い
- コミットは作業内容をローカルリポジトリに記憶する
- プッシュはリモートリポジトリへ作業した内容を共有できる


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- 編集内容を正確に表すようなメッセージ


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- ローカルでマージするフローは自分のPC上で作業して統合まですること
- プルリクエストでマージするフローはリモートリポジトリ上で、チームの人や、担当者にレビュー依頼して、承認を得てから統合すること


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- 自分以外の人が書いたソースコードの内容を把握する必要がるため、書いた人と相談して確認してから統合する
